# 学习仪表盘

数据：`wiki/` 的 YAML（已排除 index 页）。正文不解析掌握度。

## 今日下一步

```dataview
TASK
FROM "wiki"
WHERE !completed
LIMIT 20
```

## 待审 diff 包

```dataview
TABLE file.link AS "文件"
FROM "diff"
WHERE contains(file.name, "MANIFEST") OR contains(file.path, "_ingest") OR contains(file.path, "lint")
SORT file.mtime DESC
```

## 🔴 进行中 / 刚开始（level 1–2）

```dataview
TABLE file.link AS "页", kind, status, understanding_level AS "level", need_practice AS "待实操", last_review AS "上次"
FROM "wiki"
WHERE understanding_level <= 2 AND understanding_level >= 0 AND status != "已归档" AND kind != "index"
SORT understanding_level ASC
```

## 📝 待实操

```dataview
TABLE file.link AS "页", understanding_level AS "level", source, last_review AS "上次"
FROM "wiki"
WHERE need_practice = true AND kind != "index"
SORT last_review ASC
```

## ✅ 已理解及以上

```dataview
TABLE file.link AS "页", kind, understanding_level AS "level", status
FROM "wiki"
WHERE (status = "已理解" OR understanding_level >= 3) AND kind != "index"
SORT understanding_level DESC
```

## 🕸️ 超 30 天

```dataview
TABLE file.link AS "页", last_review, understanding_level AS "level", status
FROM "wiki"
WHERE last_review AND last_review < date(today) - dur(30 days) AND kind != "index"
SORT last_review ASC
```

## 📊 level / status 分布

```dataview
TABLE length(rows) AS "篇数"
FROM "wiki"
WHERE understanding_level AND kind != "index"
GROUP BY understanding_level
SORT understanding_level DESC
```

```dataview
TABLE length(rows) AS "篇数"
FROM "wiki"
WHERE status AND kind != "index"
GROUP BY status
```

## 📂 按 source

```dataview
TABLE rows.file.link AS "页", rows.understanding_level AS "levels", rows.status AS "状态"
FROM "wiki"
WHERE source AND kind != "index"
GROUP BY source
```

## 🏷️ 按 source_type

```dataview
TABLE file.link AS "页", source_type, understanding_level AS "level"
FROM "wiki"
WHERE source_type AND kind != "index"
SORT source_type ASC
```
