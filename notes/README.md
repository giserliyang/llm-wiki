# 个人原子笔记层（你写，LLM 勿改）

这里是 **你的大脑外挂**：疑难点、洞见、实战记录。

- 平铺即可，**不要按主题建深层子文件夹**
- 用 YAML `tags` 分主题，用仪表盘当「虚拟文件夹」
- 用模板 `templates/atomic-note.md`

## 灵感随手记（inbox）

路径：`notes/inbox/`

1. 手机/桌面 Obsidian 打开本 Vault  
2. 在 `notes/inbox/` 新建当日笔记，或插入模板 `quick-capture`  
3. **30 秒记完**，不求完整  
4. **每周清一次**：升为 `notes/` 原子笔记 / 收成 `raw/bookmarks/` / 丢弃  

入口：`dashboards/学习仪表盘.md`

## 创建原子笔记的时机

真正卡住 / 真正有洞见 / 真正用起来时。  
**不要**按教程目录预建空壳。

## 字段纪律

| 字段 | 何时改 |
| --- | --- |
| `understanding_level` | 真的能默写/讲懂/改代码时 |
| `need_practice` | 实操完成或发现必须实操时 |
| `last_review` | 真正重看并有所得时 |
| `status` | 阅读阶段变化或归档时 |
