## 要点

### 变量与赋值

- 语法：`变量名 = 值`，等号表示**绑定**而非数学等式
- 变量的创建与赋值同时完成，不赋值就不能使用
- `a = 10` 中 `a` 本身没有类型，类型属于数据 `10`

### 常量

- Python 无强制常量，约定：全大写下划线分隔（`MAX_USERS = 1200`）
- 强行修改不报错，靠程序员自觉

### 标识符规则

| 规则 | 说明 |
| --- | --- |
| 字符限制 | 数字、字母、下划线，不能以数字开头 |
| 大小写 | 区分大小写 |
| 关键字 | 不能用 Python 保留字（如 `def`、`class`、`if`） |
| 内置函数 | 避免与 `print`、`list` 等内置函数同名 |
| 推荐风格 | 蛇形命名（`user_name`） |

### 注释

- 单行：`# 内容`（`#` 后建议加空格）
- 多行：本质是三引号字符串，非真正注释语法
- 文件编码注释：`# coding=utf-8`（Python 3 默认 UTF-8，通常可省略）

### 运算符速查

| 类别  | 运算符                                         |
| --- | ------------------------------------------- |
| 算数  | `+ - * / // % **`                           |
| 赋值  | = += -= *= /= //= %= **=                    |
| 比较  | == != > < >= <=                             |
| 逻辑  | `and or not`                                |
| 布尔  | `bool()` 转换；`bool(0)=False`, `bool(1)=True` |

### 常见陷阱

> 来自 `[[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##2.1. 变量]]`

- 用 `=` 做赋值而非比较（比较用 `==`）
- 常量可以强行修改，不会被解释器拦截
- 多行注释本质是字符串，放在代码中会作为表达式求值（通常忽略）
