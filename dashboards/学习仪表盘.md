# 学习仪表盘

数据源是 `notes/` 原子笔记。**这里只展示，不承载正文。**

## 🔴 重点复习（level < 3）

```dataview
TABLE file.link AS "笔记", understanding_level AS "level", source AS "来源"
FROM "notes"
WHERE understanding_level < 3 AND status != "已归档"
SORT understanding_level ASC
```

## 📝 待实践清单

```dataview
TABLE file.link AS "笔记", source AS "来源", last_review AS "上次复习"
FROM "notes"
WHERE need_practice = true
SORT file.mtime DESC
```

## 🕸️ 超过 30 天没碰

```dataview
TABLE file.link AS "笔记", last_review AS "上次", understanding_level AS "level"
FROM "notes"
WHERE last_review < date(today) - dur(30 days)
SORT last_review ASC
```

## 📊 掌握度分布

```dataview
TABLE length(rows) AS "篇数"
FROM "notes"
GROUP BY understanding_level
SORT understanding_level DESC
```

## 📂 按来源教程/素材分组

```dataview
TABLE rows.file.link AS "笔记", rows.understanding_level AS "levels"
FROM "notes"
GROUP BY source
```

## 🏷️ 按来源类型

```dataview
TABLE file.link AS "笔记", source_type AS "类型", understanding_level AS "level"
FROM "notes"
WHERE source_type
SORT source_type ASC
```

## ✅ 已理解待实战

```dataview
TABLE file.link AS "笔记", understanding_level AS "level"
FROM "notes"
WHERE status = "已理解" AND need_practice = true
```

## 🐍 仅 Python

```dataview
TABLE file.link AS "笔记", understanding_level AS "level", status AS "状态"
FROM "notes" AND #python
SORT understanding_level ASC
```
