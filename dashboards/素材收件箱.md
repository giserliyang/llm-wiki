# 素材收件箱

`raw/` 入库与进度。

## 全部素材

```dataview
TABLE source_type AS "类型", status AS "状态", file.mtime AS "修改"
FROM "raw"
SORT file.mtime DESC
```

## 未读 / 进行中

```dataview
LIST
FROM "raw"
WHERE status != "已理解" AND status != "已归档"
SORT file.mtime DESC
```

## 未完成进度任务

```dataview
TASK
FROM "raw"
WHERE !completed
GROUP BY file.link
```

## 已写进 wiki 的拆解页

```dataview
TABLE file.link AS "wiki 页", kind, understanding_level AS "level", status
FROM "wiki"
WHERE source
SORT file.mtime DESC
```
