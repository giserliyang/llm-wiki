## 要点

### 变量与赋值

- 语法：`变量名 = 值`，等号表示**绑定**而非数学等式 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##2.1. 变量]]
- 变量的创建与赋值同时完成，不赋值就不能使用 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##2.1. 变量]]
- `a = 10` 中 `a` 本身没有类型，类型属于数据 `10` [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##2.1. 变量]]

```python
# 这一步是为了解决【重复使用同一数值】问题
weight = 65.2
print('体重是', weight)  # 修改体重只需改一行
```

### 常量

- Python 无强制常量，约定：全大写下划线分隔（`MAX_USERS = 1200`）[[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##2.3. 常量]]
- 强行修改不报错，靠程序员自觉 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##2.3. 常量]]
