# 三层架构

## 摘要

Raw Sources → Wiki → Schema：素材只读归档、知识结构化编译、规则约束 LLM，缺一层就会变成「伪 Wiki」。

## 核心内容

### 1. Raw Sources（原始素材层）

- 教程、视频字幕、网页书签、截图、PR 记录、会议纪要
- 命名：`YYYYMMDD_主题_来源`（例：`20260912_LLMWiki_Karpathy_bookmark.md`）
- **只读不改**，保证溯源
- 目录结构参考：

```
raw/
├── docs/          # 官方文档、论文
├── prs/           # 代码 PR / 评审意见
├── incidents/     # 故障复盘
├── meetings/      # 会议记录
├── images/        # 截图、架构图
└── others/        # 书签导出、零散素材
```

> 来源：[[raw/bookmarks/别再用RAG当"冤大头"！Karpathy的LLM Wiki——知识管理的新解法-腾讯云开发者社区-腾讯云.md]] §"Raw Sources 原始素材层：只读不改，保留溯源能力"

> [!note] 文章原规范 vs 本库实践
> | 维度 | 文章原规范 | 本库实践 | 备注 |
> | --- | --- | --- | --- |
> | raw 子目录 | `docs / prs / incidents / meetings / images / others` | `bookmarks / tutorials / videos / images / others` | 本库以素材类型（书签/教程/视频）为一级分类，未建 docs/prs/incidents/meetings |
> | 命名规范 | `日期_主题_来源` | `日期_主题_来源`（一致） | 现有 bookmark 文件名已遵循 |
> | 溯源方式 | 文件名含日期主题来源 | YAML frontmatter `source: "[[raw/...]]"` + 正文引用 | 本库额外用 frontmatter 给 Dataview 查询用 |

### 2. Wiki（结构化知识层）

- 概念页 / 实体页 / 对比 / 决策 / 实战
- LLM 写入，人审核；禁止 LLM 直接改 raw/ 与 notes/
- 统一 Frontmatter 模板（参见 `templates/wiki-page.md`）
- 标准目录：

```
wiki/
├── overview.md    # 全局概览入口
├── glossary.md    # 术语表
├── concepts/      # 概念页
├── entities/      # 人物/工具/产品页
├── comparisons/   # 对比分析页
├── decisions/     # 决策记录页
├── incidents/     # 故障知识页（暂未使用）
└── links.md       # 全局链接索引
```

> [!note] 文章原规范 vs 本库实践
> | 维度 | 文章原规范 | 本库实践 | 备注 |
> | --- | --- | --- | --- |
> | wiki 子目录 | `concepts / entities / incidents / decisions / links.md / glossary.md / overview.md` | 同上，另含 `comparisons/` | 本库额外建 `wiki/comparisons/` 放对比页（如 LLM-Wiki-vs-RAG） |
> | 文件模板 | `title / status / owners / source_count / last_reviewed / sensitivity` | `title / status / kind / tags / source_count / last_reviewed`（参考 `templates/wiki-page.md`） | 本库用 `kind` 区分 concept/entity/comparison/decision，去掉 owners/sensitivity |

> [!note] 文件模板强制
> 每页须有 Frontmatter：`title / status / kind / tags / source_count / last_reviewed`；正文含摘要、核心内容、引用来源、关联页面、待补充/疑问五节。

### 3. Schema（规则层）

- 根目录 `AGENTS.md`：LLM 必须遵守的操作规则
- `prompt/ingest.md`：摄入提示词，指导 LLM 如何处理 raw/ 素材
- `prompt/lint.md`：校验提示词，定期自检 Wiki 规范性
- 关键规则：
  - 禁止修改 raw/ 与 notes/
  - 无来源不写入
  - 不确定内容标记 `> [!question] 待补充`
  - 禁止强制无关链接
  - 重要修改必须产出 diff 等待人审
  - 禁止删除，仅可标记「废弃」
- 可附加 `lint.md` 定义语法检查规则
