# 装饰器与闭包的底层机制

> 本篇拆解自 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##12. 闭包]] 和 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##13. 装饰器]]。（正文里用 `[[原文#章节]]` 带锚点）

## 我的理解

装饰器本质是高阶函数 + 闭包。用自己的话描述：`@decorator` 语法糖展开后是什么？`wrapper` 函数如何"记住"外层变量？

## 要点

1. **闭包三条件**：函数嵌套 + 内层引用外层变量 + 外层返回内层 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##12. 闭包]]
2. **cell 机制**：外层变量被封存在 `__closure__` 元组的 cell 中，不随外层函数销毁 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##12. 闭包]]
3. **装饰器本质**：`@decorator` 等价于 `func = decorator(func)`，即高阶函数调用 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##13. 装饰器]]
4. **多层装饰器**：离函数近的先执行，顺序与书写顺序相反 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##13. 装饰器]]
5. **带参装饰器**：三层嵌套，外层收配置，中层收函数，内层收参数 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##13. 装饰器]]
6. **类装饰器**：通过 `__call__` 实现，比函数装饰器更简洁 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##13.2. 类装饰器]]

```python
# 这一步是为了解决【在不修改原函数代码的前提下增强功能】问题
def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(f'{func.__name__} 耗时 {time.time()-start:.3f}s')
        return result
    return wrapper
```
