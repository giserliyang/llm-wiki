# 原子笔记

## 摘要

一篇只承载一个可独立复用的想法；用 YAML 管掌握度，用 `source` 溯源，用双链成网——是个人学习层，不由 LLM 代笔。

## 核心内容

### 何时创建

教程/文章**真正卡住**或产生洞见时，而不是按目录预建空壳。

### 必备元数据

- `understanding_level`：0–5（行为结果）
- `need_practice`：下一步行动（GTD）
- `source` / `source_type` / `source_url`
- `last_review`：真正复习过的日期

### 链接策略

- YAML：`source: "[[原文]]"` → 给 Dataview
- 正文：`[[原文#章节]]` → 给人跳转
- 反向链接面板自动聚合，原文不必手写回链

### 理解度刻度

| 值 | 含义 |
| --- | --- |
| 0 | 未读 |
| 1 | 见过 |
| 2 | 能复述 |
| 3 | 能默写 |
| 4 | 能讲懂 |
| 5 | 能改/迁移 |
