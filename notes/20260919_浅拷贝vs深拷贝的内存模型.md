# 浅拷贝vs深拷贝的内存模型

> 本篇拆解自 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##10. 浅拷贝 vs 深拷贝]]。（正文里用 `[[原文#章节]]` 带锚点）

## 我的理解

用 `id()` 函数追踪每个对象的内存地址，画出一张内存图：直接赋值、浅拷贝、深拷贝后各变量指向哪些对象？哪个变了哪个没变？

## 要点

1. **直接赋值**：两个变量指向同一个对象，修改一个另一个跟着变 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##10. 浅拷贝 vs 深拷贝]]
2. **浅拷贝**：外层容器新建，内层元素仍是原对象的引用 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##10. 浅拷贝 vs 深拷贝]]
3. **深拷贝**：外层容器及所有嵌套可变对象都递归复制，完全独立 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##10. 浅拷贝 vs 深拷贝]]
4. **不可变对象**：深拷贝不会复制不可变对象（int、str、tuple 等），直接引用 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##10. 浅拷贝 vs 深拷贝]]
5. **元组特例**：元组内只含不可变对象时，deepcopy 无效果 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 8 章 函数进阶##10. 浅拷贝 vs 深拷贝]]

```python
# 这一步是为了解决【修改副本不影响原数据】问题
import copy
a = [1, 2, [3, 4]]
b = copy.copy(a)    # 浅拷贝：a[2] 和 b[2] 指向同一列表
c = copy.deepcopy(a)  # 深拷贝：a[2] 和 c[2] 是独立对象
```
