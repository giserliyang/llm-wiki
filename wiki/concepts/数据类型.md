# 数据类型

## 摘要

Python 中的数据都有对应的类型。本章涵盖整型、浮点型、字符串的定义与用法，以及类型转换和字符编码的基础知识 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础]]。

## 核心内容

### 数据类型概述

就像生活中的物品有分类一样，数据也有类型 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.1. 概述]]。

常见数据类型：

| 类型名称 | 英文名     | 举例                     | 说明                                                                                      |
| ---- | ------- | ---------------------- | --------------------------------------------------------------------------------------- |
| 整型   | `int`   | `5`, `-3`, `0`, `2025` | 不带小数点的数 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.1. 概述]]    |
| 浮点型  | `float` | `3.14`, `-0.01`        | 带小数点的数 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.1. 概述]]     |
| 字符串  | `str`   | `"Hello"`, `'Python'`  | 文本，要用引号包起来 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.1. 概述]] |

> [!tip]
> 数据类型不只上述三种，后续章节还会讲解更多类型 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.1. 概述]]。

**查看数据类型：** 使用 `type()` 函数 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.2. 查看数据类型]]。

```python
print(type('张三'))   # <class 'str'>
print(type(18))       # <class 'int'>
print(type(72.5))     # <class 'float'>
```

> [!warning]
> **变量无类型，数据有类型。** `a = 10` 中 `a` 没有类型，但 `a` 关联的数据 `10` 是整型 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.2. 查看数据类型]]。

### 整型（int）

- Python 中的整型可以是**任意大小**的整数，包括负整数 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.3. 整型]]。
- 可用下划线分隔数字提高可读性（Python 3.6+）：`num = 10_000_000` [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.3. 整型]]。
- Python 对超大整数转字符串有 4300 位限制（Python 3.11+），可通过 `sys.set_int_max_str_digits(0)` 解除 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.3. 整型]]。

### 浮点型（float）

- 带小数点的数字：`3.14`、`-0.5`、`2.0` [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.4. 浮点型]]。
- 支持科学计数法：`3.4e+2`（即 3.4 × 10²）、`1.496E8` [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.4. 浮点型]]。

### 字符串（str）

**四种写法：**

| 写法 | 示例 | 适用场景 |
| --- | --- | --- |
| 单引号 | `'你好'` | 单行字符串（最常用） |
| 双引号 | `"你好"` | 同单引号 |
| 三单引号 | `'''你好'''` | 多行字符串，可作注释 |
| 三双引号 | `"""你好"""` | 多行字符串，可作注释或 docstring |

[[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.5. 字符串]]

**字符串格式化输出（三种方式）：**

1. 加号拼接（麻烦，只能字符串之间拼接）：`'我叫' + name` [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.5. 字符串]]。
2. 占位符（`%s`、`%d`、`%f`）：`'我叫%s' % name` [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.5. 字符串]]。
3. **f-string（推荐）**：`f'我叫{name}'` — 目前 Python 最推荐的方式 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.5. 字符串]]。

**转义字符：**

| 转义字符 | 含义 |
| --- | --- |
| `\'` | `'` |
| `\"` | `"` |
| `\n` | 换行 |
| `\\` | `\` |
| `\b` | 退格 |
| `\r` | 回车（覆盖输出） |
| `\t` | 水平制表符 |

[[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##5.5. 字符串]]

### 数据类型转换

将一种类型的数据变成另一种类型 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##6.1. 概述]]。

| 函数 | 说明 | 示例 |
| --- | --- | --- |
| `int(x)` | 转整数 | `int('18')` → `18` |
| `float(x)` | 转浮点数 | `float('3.14')` → `3.14` |
| `str(x)` | 转字符串 | `str(18)` → `'18'` |

[[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##6.3. 具体转换方式]]

**常见需要类型转换的场景：**

1. 用户输入的内容是字符串，需转数值才能做数学运算 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##6.2. 为什么要数据类型转换]]。
2. 文件写入时需将其他类型转为字符串 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##6.2. 为什么要数据类型转换]]。
3. 从数据库读取的内容是字符串，需转换才能运算 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##6.2. 为什么要数据类型转换]]。

### 字符编码

计算机存储数据时进行编码，读取时进行解码，编码与解码必须遵循相同规范，否则出现乱码 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.1. 概述]]。

**常见编码方式：**

| 编码 | 说明 |
| --- | --- |
| ASCII | 28 个字符（英文字母、数字、符号）[[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.2. 常见编码方式]] |
| ISO 8859-1 | 在 ASCII 基础上扩展，支持西欧语言，256 个字符 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.2. 常见编码方式]] |
| GB2312 | 简体中文常用汉字和符号，约 6763 个 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.2. 常见编码方式]] |
| GBK | 兼容 GB2312，收录 2 万+ 字符，支持简繁体 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.2. 常见编码方式]] |
| **UTF-8** | 国际通用（万国码），支持所有语言，向下兼容 ASCII，**现代互联网最常用** [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.2. 常见编码方式]] |

> [!success]
> 最佳实践：实际开发中几乎都采用 UTF-8 编码保存文件 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.2. 常见编码方式]]。

> [!tip]
> Python 3 默认使用 UTF-8 编码，通常可以不写文件编码声明 [[raw/tutorials/python/20260919_Python教程_尚硅谷.md#第 3 章 Python 核心基础##4.2. 常见编码方式]]。
