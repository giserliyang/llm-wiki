# 素材收件箱

看 `raw/` 进了什么、读没读完。

## 全部原始素材

```dataview
TABLE source_type AS "类型", status AS "状态", file.mtime AS "入库/修改"
FROM "raw"
SORT file.mtime DESC
```

## 未读 / 进行中

```dataview
LIST
FROM "raw"
WHERE status != "已理解" AND status != "已归档"
SORT file.mtime DESC
```

## 按类型统计

```dataview
TABLE length(rows) AS "篇数"
FROM "raw"
GROUP BY source_type
```

## 有未完成阅读进度任务的教程

> 任务里的链接应是 `[[笔记名#标题]]`（Templater 模板已按此生成）。  
> 点标题可跳到教程对应章节；也可点分组上的文件名先打开教程。

```dataview
TASK
FROM "raw"
WHERE !completed
GROUP BY file.link
```
